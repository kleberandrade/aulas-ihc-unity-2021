Unity game-interface exercises from the 2021 human-computer interaction classes.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/Character.unity](https://github.com/kleberandrade/aulas-ihc-unity-2021/blob/master/Assets/Scenes/Character.unity), [Assets/Scenes/Credits.unity](https://github.com/kleberandrade/aulas-ihc-unity-2021/blob/master/Assets/Scenes/Credits.unity), [Assets/Scenes/Gameover.unity](https://github.com/kleberandrade/aulas-ihc-unity-2021/blob/master/Assets/Scenes/Gameover.unity), [Assets/Scenes/Gameplay.unity](https://github.com/kleberandrade/aulas-ihc-unity-2021/blob/master/Assets/Scenes/Gameplay.unity), [Assets/Scenes/Menu.unity](https://github.com/kleberandrade/aulas-ihc-unity-2021/blob/master/Assets/Scenes/Menu.unity).
